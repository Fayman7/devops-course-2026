1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
Ответ: В SVN не копируется вся история работы с файлами на компьютер, только текущие файлы, которые потом каждый раз отправляются на сервер. Влияет скорость интернета.
2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, у SVN нет локального репозитория.
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
При работе в большими данными, при отсутствии необходимости работы со всеми файлами версии, при нужде блокировать значимые файлы проекта для обычных работников.
